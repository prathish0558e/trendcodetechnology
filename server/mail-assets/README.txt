TCT EMAIL ASSETS — drop your images in THIS folder
==================================================

The mail server reads these files on EVERY send, so you can replace them
whenever you like — no restart needed. Supported: .png .jpg .jpeg .webp

  header-banner.png   Top banner of every mail. Recommended 600 x 160 px.
  footer-banner.png   Bottom banner of every mail. Recommended 600 x 110 px.
  watermark.png       Faint logo shown BEHIND the body text (light, subtle).
  logo.png            Small header logo — used only when header-banner
                      is missing.

If a file is missing, the mail still sends fine — it falls back to the
built-in styled header/footer (dark bar with the logo + company name).

The current header/footer/watermark files are auto-generated placeholders —
replace them with your own designs whenever you want.
